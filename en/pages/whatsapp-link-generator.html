FAQ

WhatsApp link questions

What is a wa.me link?

It is WhatsApp's official click-to-chat link: it opens a chat with a number without saving it to contacts. It opens the WhatsApp app on phones and WhatsApp Web on computers.

Is the WhatsApp link generator free?

Yes. The tool is completely free and needs no sign-up. The links you create never expire.

Why doesn't my link work?

Usually the number has a leading 0 or is missing the country code. It should look like 14155550123, and the number must use WhatsApp.

Can I change the ready message later?

Yes, just create a new link with the new message. The message lives inside the link itself and is not stored anywhere.
