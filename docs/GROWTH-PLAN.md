## ۳. قوانین اجرا (قفل)

1. **هر روز یک کار** (یا یک دسته کوچک از یک کار) از اولین کار باز در پایین‌ترین فاز. فاز بعد فقط وقتی شروع می‌شود که کارهای فاز قبل انجام یا مسدود باشند.
2. **هیچ اطلاعات ساختگی:** قیمت، گواهی، نام مشتری، آمار و ادعا فقط از محتوای موجود سایت و فایل‌های config. اگر اطلاعات لازم نیست، کار را `[!]` کن و دلیل بنویس.
3. **مناطق ممنوع** مگر کار صریحاً بگوید: `api/`، `admin/`، `storage/`، `database/`، بلوک geo-redirect و هدرهای امنیتی در `.htaccess`، فایل‌های deploy. حذف صفحه ممنوع است؛ به‌جای آن 301 بده.
4. **دروازه انتشار:** قبل از هر push باید `npm run growth:check` پاس شود. اگر شکست خورد، درست کن یا تغییر را برگردان. کد خراب هرگز push نمی‌شود.
5. **تولیدکننده‌ها را هم درست کن:** اگر HTML از اسکریپتی در `scripts/` ساخته می‌شود، اسکریپت را هم اصلاح کن تا اجرای بعدی تغییر را پاک نکند.
6. **هر ۵ زبان** (fa در ریشه، tr/en/ru/ar) با هم و با کیفیت بومی. ترجمه ماشینی تحت‌اللفظی ممنوع.
7. **عنوان ≤ ۶۰ کاراکتر، description بین ۱۲۰ تا ۱۵۵ کاراکتر**، کلمه کلیدی اصلی در ابتدای عنوان، و یک دلیل روشن برای کلیک (قیمت واقعی، زمان تحویل، اصالت، مشاوره رایگان).
8. پیام commit: `growth(<شناسه>): <خلاصه>`؛ هر روز یک خط در `docs/growth/CHANGELOG.md`.
