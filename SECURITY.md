# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Report suspected vulnerabilities privately to **security@bizdavar.com** with:

- affected component or path
- reproduction steps
- expected and actual behavior
- impact assessment, if known
- screenshots or proof-of-concept material that does not expose third-party data

We will acknowledge valid reports as soon as practical and coordinate remediation before public disclosure.

## Scope

This repository contains the public website and related deployment tooling. Never commit production credentials, API keys, private customer data, database dumps, or server secrets.

## Supported code

Security fixes are applied to the current `main` branch. Older snapshots are not guaranteed to receive patches.
