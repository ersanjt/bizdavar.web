Выбор датчиков уровня, давления или предельного уровня is not brochure shopping: media, temperature, process connection and certificates decide the model. Bizdavar supplies VEGA and, for gas/flame, Prosense with a clear proforma.

Measurement type

  • Radar (VEGAPULS) — non-contact level.
  • Pressure (VEGABAR) — process pressure / hydrostatic level.
  • Switch (VEGAPOINT) — compact point level.

Official data: vega.com.

Certificates

State Ex, SIL and food hygiene in the first message or the order code will be wrong.

Supply path

Process → model → proforma → shipment. See industrial supply and VEGA for Iran projects. Quote: contact.
