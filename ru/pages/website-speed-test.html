    Что такое оценка скорости и Core Web Vitals?

    Оценка Performance

    Число от 0 до 100, которое Google рассчитывает по нескольким метрикам скорости. 90+ — зелёная зона (отлично), 50–89 — оранжевая, ниже 50 — красная.

    Core Web Vitals

    Три официальные метрики Google для опыта пользователя: LCP (загрузка основного контента), INP (отклик на клик) и CLS (стабильность макета). Влияют на SEO.

    Почему скорость важна

    Каждая секунда задержки снижает конверсию, а большинство мобильных пользователей закрывают страницу, которая грузится дольше 3 секунд.

    Как ускорить сайт

    1. Переведите изображения в WebP или AVIF, сожмите их и задайте правильные размеры.
    2. Загружайте изображения и видео ниже первого экрана через lazy loading.
    3. Уберите лишние плагины и сторонние скрипты (чаты, пиксели, слайдеры).
    4. Включите кеширование, сжатие Brotli/Gzip и CDN, например Cloudflare.
    5. Выберите быстрый хостинг с достаточными CPU и памятью рядом с аудиторией.
    Вопросы и ответы

    Вопросы о проверке скорости сайта

    Как работает проверка скорости сайта?

    Адрес отправляется в Google PageSpeed Insights. Google загружает страницу через Lighthouse и возвращает оценку, метрики и рекомендации — те же данные, по которым Google оценивает скорость.

    Какая оценка считается хорошей?

    90–100 — отлично, 50–89 — средне, ниже 50 — плохо. Для Core Web Vitals: LCP до 2,5 с, INP до 200 мс и CLS до 0,1.

    Почему мобильная оценка ниже, чем для ПК?

    Мобильный тест имитирует слабый процессор и медленную сеть. Большинство визитов мобильные, поэтому Google ранжирует по мобильной оценке.

    Почему оценка меняется от проверки к проверке?

    Нагрузка на сервер, реклама, сторонние скрипты и сеть каждый раз разные. Сделайте несколько проверок и смотрите на среднее.
