Основы

Что такое IP-адрес?

Внешний IP

Идентификатор, который провайдер выдаёт вашему подключению; сайты отправляют ответы на него. Устройства за одним роутером обычно делят один внешний IP.

IPv4 и IPv6

IPv4 — четыре числа вроде 85.15.20.1, их число ограничено. IPv6 — новое поколение с огромным количеством адресов; если провайдер его поддерживает, вы увидите оба.

Частный IP

Адреса вида 192.168.x.x работают только внутри домашней или офисной сети и не видны из интернета.

Когда нужен IP-адрес?

  1. Сообщите внешний IP техподдержке для настройки удалённого доступа, видеонаблюдения или сервера.
  2. Если сайт заблокировал вас по ошибке, отправьте им свой IP для разблокировки.
  3. Откройте эту страницу после включения VPN, чтобы убедиться, что IP сменился.
  4. Для серверов, камер и постоянного доступа закажите у провайдера статический IP.
Вопросы и ответы

Вопросы об IP-адресе

Какой у меня IP и как его узнать?

Ваш внешний IP появился вверху страницы сразу после её открытия. Это адрес, который сайты и сервисы видят у вашего подключения.

Насколько точно местоположение?

Местоположение по IP обычно определяется с точностью до города или узла провайдера, а не до улицы. В мобильном интернете может отображаться другой город.

Можно ли по IP найти мой домашний адрес?

Нет. IP показывает только провайдера и примерный район. Данные абонента есть только у провайдера и выдаются лишь по решению суда.

Почему мой IP постоянно меняется?

Большинство провайдеров выдают динамический IP, который меняется после перезагрузки роутера или при перемещении в мобильной сети.

Что такое статический IP и нужен ли он?

Статический IP не меняется. Он нужен для серверов, камер, корпоративного VPN и удалённого доступа; провайдеры дают его за ежемесячную плату.
