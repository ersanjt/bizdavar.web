About the module

BizSwap is a presale and token swap module engineered by the Bizdavar team — users convert stablecoin to project tokens without leaving the project website.

Includes Web3 wallet UI, swap widget with token picker, quick percentage buttons, slippage/minimum received calculation, on-chain transaction feedback and BEP-20 smart contract integration.
