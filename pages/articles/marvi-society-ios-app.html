خلاصه پروژه

برند lifestyle/creator به اپ native نیاز داشت — نه PWA. مسیر: wireframe → UI kit → Swift → TestFlight → App Store. جزئیات و لینک دانلود در نمونه‌کار Marvi Society و پورتفولیو.

تکنولوژی

  • API رویداد و پروفایل creator
  • Push و deep link برای دعوت
