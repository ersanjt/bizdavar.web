IP عمومی

شناسه‌ای که اپراتور به اتصال شما می‌دهد و سایت‌ها با آن پاسخ را به شما برمی‌گردانند. همه دستگاه‌های پشت یک مودم معمولاً یک IP عمومی دارند.

IPv4 و IPv6

IPv4 چهار عدد مثل 85.15.20.1 است و تعدادش محدود است. IPv6 نسل جدید با آدرس‌های بسیار بیشتر است؛ اگر اپراتورتان پشتیبانی کند، هر دو را می‌بینید.

IP خصوصی

آدرس‌هایی مثل 192.168.x.x فقط داخل شبکه خانه یا شرکت معنا دارند و از اینترنت دیده نمی‌شوند.

چه وقت IP به کار می‌آید؟

  1. برای تنظیم دسترسی ریموت، دوربین مداربسته یا سرور، IP عمومی را به پشتیبانی بدهید.
  2. اگر سایتی شما را به‌اشتباه مسدود کرده، IP را برای رفع مسدودیت ارسال کنید.
  3. بعد از روشن کردن VPN، این صفحه را باز کنید تا مطمئن شوید IP عوض شده است.
  4. برای سرورها، دوربین‌ها و دسترسی ثابت از اپراتور IP ثابت (Static IP) بگیرید.

پرسش‌های رایج درباره IP

IP من چیست و چطور پیدایش کنم؟

همین که این صفحه را باز کردید، IP عمومی شما بالای صفحه نمایش داده شد. این همان آدرسی است که سایت‌ها و سرویس‌ها از اتصال شما می‌بینند.

موقعیت نمایش‌داده‌شده چقدر دقیق است؟

موقعیت IP معمولاً در حد شهر یا مرکز اپراتور است، نه آدرس دقیق شما. در اینترنت موبایل ممکن است شهر دیگری نمایش داده شود.

آیا کسی می‌تواند با IP آدرس خانه‌ام را پیدا کند؟

خیر. IP فقط اپراتور و منطقه تقریبی را نشان می‌دهد. مشخصات مشترک فقط نزد اپراتور است و با حکم قانونی قابل دسترسی است.

چرا IP من مدام عوض می‌شود؟

بیشتر اپراتورها IP پویا (Dynamic) می‌دهند که با خاموش‌وروشن شدن مودم یا جابه‌جایی در اینترنت موبایل تغییر می‌کند.

IP ثابت چیست و لازم دارم؟

IP ثابت هیچ‌وقت تغییر نمی‌کند و برای سرور، دوربین، VPN سازمانی و دسترسی ریموت لازم است. اپراتورها آن را با هزینه ماهانه ارائه می‌دهند.

سرور، VPN سازمانی یا IP ثابت لازم دارید؟

تیم بیزدوار راه‌اندازی و مدیریت سرور، امنیت، بکاپ و مانیتورینگ را برای کسب‌وکار شما انجام می‌دهد.
